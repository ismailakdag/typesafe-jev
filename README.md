# typesafe-jev

TypeSafe (System One / Jev) deneme alani.

- Python SDK: `typesafe-sdk` (uv ile kurulu)
- Skill: `typesafe@typesafe-ai` (Claude Code plugin, user scope)

## Kurulum
1. `cp .env.example .env` ve `TYPESAFE_API_KEY` degerini doldur.
2. `uv run python smoke_test.py`
